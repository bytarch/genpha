The AI Agent that Runs Tasks in Your Browser.

Genpha is a simple browser extension that understands and executes commands, automating navigation and input tasks on any webpage.

Core Commands Genpha Masters

Input Automation

Accurately fill forms, select options, and type dynamic text without needing complex selectors.

Smart Navigation

Execute precise clicks, follow links, and navigate complex routing systems based on conversational instructions.

Local Execution & Privacy

Genpha runs entirely as an extension, meaning your data stays local and confidential.

Multi-Tab Orchestration

Seamlessly switch between tabs, copy data from one, and input it into another as part of a single workflow.

Manual Installation Required

Genpha is currently in Alpha and is not yet published on the Chrome Web Store. You must install it manually using Developer Mode.

1

Download Source Code

Click button below to automatically download the source code as a .zip file from the main branch.

Download Source Code
2

Open Extensions Page

In your Chrome browser, navigate to the extensions management page by typing:

chrome://extensions
3

Enable Developer Mode

Look for the toggle switch in the top-right corner of the page labeled Developer mode and turn it ON.

4

Load the Extension

You have two options:

  • Option A (Easiest): Drag and drop the downloaded .zip file directly onto the chrome://extensions page.
  • Option B: Click the Load unpacked button and select the unzipped folder.
